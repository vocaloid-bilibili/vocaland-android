## 一、P1 明显影响使用

### 数据 / 交互 bug（设备实测）

- [x] **D1** 首页「最近评论 / 最近评分」显示内部标识
  - 现象：`歌曲 #61114`、`page:home`、`ranking:vocaloid-weekly:114`、`歌手 #1723`、`标签 #456`
  - 位置：`ui/home/HomeSections.kt`（最近评论/评分 section）、可能未使用 `util/Formatters.kt: targetLabel()`
  - 方案：统一走 `targetLabel(targetKey)`，未知类型降级为「评论」；不得暴露 `page:` / `ranking:` 原始 key
  - 证据：`.tmp/review/device/004_home_scroll2.png`、`006_home_bottom.png`

- [x] **D2** 歌单简介 HTML 实体未解码
  - 现象：简介显示 `&#10;`、`&amp;` 等字面量，换行丢失
  - 位置：`ui/playlist/PlaylistScreen.kt`、`ui/playlist/PlaylistDetailScreen.kt`
  - 方案：新增统一 `decodeHtmlEntities()`（`Html.fromHtml(FROM_HTML_MODE_LEGACY)` 或替换常见实体），展示层统一调用
  - 证据：`.tmp/review/device/045_playlist_square.png`

- [-] **D3** 通知中心「全部」筛选点击无效
  - 现象：点「全部」后选中态与列表均不变化，界面字节级不变
  - 位置：`ui/notifications/NotificationsScreen.kt`（chip 状态/查询 key 解耦）
  - 方案：选中态与请求过滤条件同源；空数据也必须切换选中态
  - 证据：`.tmp/review/device/068_notifications_dark.png`、`069b_notif_all.png`

- [x] **D4** 标签图鉴顶部计数错误
  - 现象：顶部「共 0 个标签」，下方实际渲染 45 个
  - 位置：`ui/tag/TagIndexScreen.kt`
  - 方案：计数改为各分组求和，或移除该行
  - 证据：`.tmp/review/device/040_tag_atlas.png`、`041b.png`

- [~] **D5** 首页连续滑动 ANR（需真机复核）
  - 现象：1.3s 内连续两次 swipe 触发系统 ANR，「等待 5000ms for MotionEvent」「spent 7094ms」「Skipped 38 frames」
  - logcat 主线程停在 `ThreadedRenderer.syncAndDrawFrame`
  - 位置：`ui/home/HomeScreen.kt` / `ui/home/HomeSections.kt` / `ui/components/NetworkImage.kt`
  - 方案：降低首页绘制成本（图片降采样、卡片预加载收敛、减少同屏大图数量）；先做安全优化，真机复测后定性
  - 证据：`.tmp/review/device/007_home_vote.png`、`008_after_anr.png`

### 体验缺陷（代码确认）

- [x] **D6** 全局缺少软键盘（IME）避让
  - 位置：`ui/VocaLandApp.kt` PageScaffold 内容区（未消费 IME inset）；`ui/playlist/AddToPlaylistSheet.kt:184`、`AddSongsToPlaylistSheet.kt:169`（固定高度且不可滚动）
  - 影响：评论/回复、设置、歌单编辑、自定义排行、钱包订单号等 10+ 输入框被键盘遮挡
  - 方案：PageScaffold 内容统一 `.imePadding()`；底部弹窗单独加 `imePadding` 并允许滚动

- [x] **D7** 「我的」页路由依赖中文文案字面量
  - 位置：`ui/VocaLandApp.kt:458-477`（`when (title) { "我的收藏" -> ... }`）
  - 影响：改文案即静默跳「正在迁移」占位页
  - 方案：改为显式回调（`onOpenFavorites` / `onOpenPlaylists` / `onOpenUserDetail` / `onOpenTagIndex` / `onOpenStat` / `onOpenCustomRanking`），显示文案与路由彻底解耦

- [x] **D8** 播放器三项设置不持久化
  - 位置：`ui/player/PlayerScreen.kt:157-160`（`rememberSaveable` 的 showSettings/videoBackgroundEnabled/danmakuEnabled/danmakuLimit）
  - 方案：并入 `PlayerVideoPreferences`（DataStore），与帧率/渐隐同源

- [x] **D9** 高频操作触控区 < 48dp
  - `ui/stat/StatFilterPanel.kt:754-768` 艺人 chip 内 16dp 的 ×
  - `ui/ranking/RankingScreen.kt:452-459` 「回到最新」纯文本 clickable
  - `ui/playlist/PlaylistDetailScreen.kt:554-575` 上/下移 `IconButton` 被 `.size(24.dp)` 压小
  - 方案：统一 48dp 命中区；Chip 的删除图标独立可点区域，不与 chip 本体抢手势
